## Types of Random Variables

Random variables can be classified into three main types:

1. **Discrete Random Variables**: These take on a countable number of distinct values. Example: The number of heads in 10 coin flips.
2. **Continuous Random Variables**: These take on an infinite number of possible values within a given range. Example: The height of students in a class.
3. **Mixed Random Variables**: These have both discrete and continuous components. Example: A random variable that is 0 with probability 0.5 and otherwise follows a normal distribution.


## Cumulative Distribution Function (CDF)

The cumulative distribution function (CDF) of a random variable \(X\) is defined as:

$$
F_X(x) = P(X \leq x)
$$

The CDF helps us to define the properties of a general random variable whether it be discrete, continuous, or mixed. </br>
It provides a complete description of the probability distribution of the random variable.


## Probability Density Function (PDF)

Properties of a PDF: 
    Any non-negative piecewise continuous function \(f_X(x)\) whose integral over the entire space is equal to 1 can be considered a valid PDF. 
    The PDF is used to describe the likelihood of a continuous random variable taking on a specific value.
