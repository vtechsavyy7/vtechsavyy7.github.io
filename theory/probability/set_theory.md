## Set operations

1. Union of sets: The union of two sets A and B, denoted by A ∪ B, is the set of all elements that belong to either A or B or both.
2. Intersection of sets: The intersection of two sets A and B, denoted by A ∩ B, is the set of all elements that belong to both A and B.
3. Complement of a set: The complement of a set A, denoted by A', is the set of all elements that do not belong to A.
4. Difference of sets: The difference of two sets A and B, denoted by A - B, is the set of all elements that belong to A but not to B.

### Disjoint Sets

## Properties of Set Operations

- Commutative property: A ∪ B = B ∪ A and A ∩ B = B ∩ A
- Associative property: (A ∪ B) ∪ C = A ∪ (B ∪ C) and (A ∩ B) ∩ C = A ∩ (B ∩ C)
- Distributive property: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) and A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
