## Real Number System

From an abstract algebraic perspective, the real number system can be defined as a **complete ordered field**. 

### Field in Abstract Algebra

    A field is a set \(F\) equipped with two binary operations: addition (+) and multiplication (·), satisfying the following properties:

- **Closure**: For any two elements $a, b \in F$, both $a + b$ and $a \cdot b$ are also in $F$.
- **Associativity**: For any three elements $a, b, c \in F$, we have $(a + b) + c = a + (b + c)$ and $(a \cdot b) \cdot c = a \cdot (b \cdot c)$.
- **Commutativity**: For any two elements $a, b \in F$, we have $a + b = b + a$ and $a \cdot b = b \cdot a$.
- **Identity Elements**: There exist two distinct elements $0$ and $1$ in $F$ such that for any element $a \in F$, we have $a + 0 = a$ and $a \cdot 1 = a$.
- **Additive Inverses**: For every element $a \in F$, there exists an element $-a \in F$ such that $a + (-a) = 0$.
- **Multiplicative Inverses**: For every non-zero element $a \in F$, there exists an element $a^{-1} \in F$ such that $a \cdot a^{-1} = 1$.
- **Distributivity**: For any three elements $a, b, c \in F$, we have $a \cdot (b + c) = (a \cdot b) + (a \cdot c)$.

### Irrational Numbers

- Non-existence of the square root of 2 in the rational numbers can be proven by contradiction. A whole number can be proven to be both odd and even, which is a contradiction.
- Relation to a unit square: Take a unit square with side length 1 and apply pythagoras' theorem to find the length of the diagonal. The length of the diagonal is \(\sqrt{2}\), which cannot be expressed as a ratio of two integers, hence it is irrational.
